## 服务端同步（同日完成）

发现问题：**服务器上的后端代码一直是旧版本**——上一轮补齐的分析看板、同意凭证、RTDN、
健康巡检等文件从未上传（`app/Services/` 只有 3 个文件，`app/Console/Commands/` 只有 4 个），
两张新表也没迁。也就是说，如果不做这一步，第二轮测试测到的会是残缺版本。

已完成的同步动作：

1. rsync 后端源码上线（22 个文件变更，`--exclude .env` 保留服务器配置）。
2. `migrate --force`：补齐 `subscription_events`、`consent_records`。
3. `optimize:clear` + **`restart php`**（清缓存后必须重启，原因见下）。
4. 修正 `storage` / `bootstrap/cache` 属主为 `www-data:www-data`。

同步过程中又修掉 2 个真缺陷：

- **服务端没有解压 gzip 请求体**。客户端在请求体 >1KB 时 gzip 压缩并带
  `Content-Encoding: gzip`，而服务端全无解压逻辑 → Laravel 收到二进制，
  `batch_id` / `events` 判为缺失，整批 422。表现是「小批量偶然成功、正常使用必失败」。
  已新增 `app/Http/Middleware/DecompressRequest.php`，挂在事件上报路由最前
  （必须在 `EventVolumeLimit` 之前，否则限流会按错误条数计费）。
- **`routes/web.php` 缺 `AnalyticsDashboardController` 的 use 导入**，
  类名被当成全局类解析，`route:list` 直接报 `Class ... does not exist`。

验证：`/api/v1/health` 200、`/admin/login` 200、`/admin/analytics` 302（需登录）、
`POST /api/v1/analytics/consent` 401（需 token）、`POST /api/v1/play/rtdn` 已注册。

### 三个部署坑（本次踩实，建议固化进脚本）

1. **rsync 必须带 `--no-owner --no-group`**：否则文件属主变成本机 uid（503），
   容器内 `www-data` 写不了 `storage` 与 `bootstrap/cache`，
   一旦触发视图编译就 500。`deploy.sh` 目前没带这个参数。
2. **清缓存后必须 `docker compose restart php`**：php-fpm 的 opcache 会记住
   「已被删除的缓存文件」路径，仅清文件不重启会得到
   `Target class [view] does not exist` 这类假故障，排查起来完全不着边际。
   `run.sh` 的 `do_optimize` 目前没有跟重启。
3. 代码是挂载进容器的（`../backend:/var/www/api`），**改代码不需要 rebuild 镜像**，
   只需 rsync → 清缓存 → 重启 php。

> `deploy.sh` / `run.sh` 的这两处参数与顺序尚未修改（改动涉及服务器执行），
> 下次部署前建议先补上，否则同样的问题会再出现一次。


### 上报时机（测试时必读）

事件**不是即产即发**：攒够 `batch_size`（默认 20 条）或**切到后台**时才 flush。
所以前台操作几下、服务端看不到数据是正常的，不是埋点坏了。
想立刻验证，按 Home 键切后台，观察 logcat 出现
`Uploaded N events (batch=...)`，再查服务端。

|---|---|

```bash

$ADB install -r builds/battery-hd-pro-debug.apk
$ADB shell am start -n com.batteryhd.app.debug/com.batteryhd.app.ui.ConsentActivity
```

抓日志：

```bash
$ADB logcat -s BatteryHD-Analytics:* *:E
```

## 6. 已知限制：模拟器测不了的部分

当前 AVD 用的是 **aosp_atd 镜像，不含 Google Play 服务**（`pm list packages` 里没有 `com.google.android.gms`），因此：

| 功能 | 状态 | 说明 |
|---|---|---|
| AdMob 横幅 / 插屏 | ❌ 不可用 | logcat 会有 `requires the Google Play Store, but it is missing`；**App 不会崩**，只是广告加载失败 |
| Play Billing 内购 / Pro 订阅 | ❌ 不可用 | `BillingClient` 连接返回 SERVICE_UNAVAILABLE |
| Play Integrity | ❌ 不可用 | 本就未接入（TODO） |
| FCM 推送 | ❌ 不可用 | 本地通知不受影响 |

**若要测广告与内购**，需要换成带 GMS 的镜像：

```bash
~/Library/Android/sdk/cmdline-tools/latest/bin/sdkmanager \
  "system-images;android-34;google_apis_playstore;arm64-v8a"
# 然后新建 AVD（avdmanager create avd -n bhd34g -k 上面的镜像）
```

镜像约 1GB+，下载后需重建 AVD。是否要装，视本轮测试重点决定。
